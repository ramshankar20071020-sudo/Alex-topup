# ALEX TOPUP — Free Fire Store
This is a frontend starter package based on the requested ALEX TOPUP Free Fire-only store.

Included:
- ALEX TOPUP branding
- Uploaded banner image
- Free Fire Diamonds, Membership and Level Up Pass products
- Checkout with Player ID
- Payment method selector
- Payment screenshot field
- Demo order history using browser localStorage
- Login/Register demo UI
- Responsive mobile/desktop design

For real online accounts, payment verification, screenshot storage and admin order management, connect Firebase or Supabase and your hosting/backend.

Payment QR images supplied by the user are included in checkout: payment-qr-1.jpg, payment-qr-2.jpg, payment-qr-3.jpg.
